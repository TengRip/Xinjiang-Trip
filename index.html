🧥 9月必勝「洋蔥式三層穿搭法」（早穿棉襖午穿紗）：
• 內層（排汗打底）：吸濕排汗長袖衫 / 輕量透氣發熱衣（切忌純棉流汗濕冷）。
• 中層（保暖核心）：輕薄羽絨背心 / 抓絨衣 / 薄羽絨外套（禾木看日出、獨庫達坂必備）。
• 外層（防風防護）：防風防雨三合一衝鋒衣（防風是防失溫第一關鍵）。
• 頭足防護配件：偏光太陽眼鏡（雪山草原防雪盲）、遮陽帽/保暖毛帽、防風手套、防滑防水徒步鞋。
💊 核心醫藥急救包清單（新疆自駕高規格備藥）：
1. 腸胃與水土不服類（最重要！）：
新疆飲食肉量大（大盤雞、羊肉串、烤包子），油脂多且容易消化不良。必備：止瀉藥（正露丸 / 蒙脫石散 / 瀉立停）、益生菌/整腸錠（若元錠 / 整腸生）、健胃消食片/消化酵素。
2. 暈車防護類（山路多彎）：
獨庫公路北段、喀納斯/禾木盤山公路彎道極多。必備：長效暈車藥（出發前30分鐘服用）、暈車貼片。
3. 感冒退燒與解熱止痛類（溫差大/高海拔）：
日夜溫差達20°C易受涼，翻越達坂海拔3400m可能輕微頭痛。必備：普拿疼 (Acetaminophen) / 布洛芬 (Ibuprofen)、綜合感冒藥 / 伏冒熱飲、抗過敏藥。
4. 乾燥與外傷護理類（極度乾燥/健行）：
新疆空氣極度乾燥，容易鼻腔乾裂出血。必備：生理食鹽水鼻噴劑 / 凡士林、保濕人工淚液/眼藥水、防水OK繃、液體絆創膏、優碘棉片。
5. 個人慢性病專屬用藥：
高血壓、心血管或個人常備處方藥請備妥 14 天份及處方箋，請務必隨身攜帶上機，切勿託運！

經典絲路超值一日遊！走 G30 連霍高速先打卡「中國死海」新疆鹽湖純白天空之鏡，再赴火洲吐魯番打卡火焰山、葡萄溝品嚐現摘甜葡萄、探訪坎兒井與蘇公塔，晚間 22:30 直達機場還車搭機。
🍇 鹽湖＋吐魯番精華一日遊時間規劃：
08:30 - 09:30｜🚗 烏魯木齊 ➡️ 新疆鹽湖 (70 km / ~50分鐘)：由「星程酒店」出發，直上 G30 連霍高速，路況極佳。
09:30 - 11:00｜🧂【天空之鏡・中國死海】新疆鹽湖景區：打卡純白晶瑩的鹽結晶棧道、巨大鹽雕，拍攝倒映著藍天與博格達雪山的夢幻天空之鏡大片（停留約 1.5 小時）。
11:00 - 12:15｜🚗 鹽湖 ➡️ 吐魯番 (110 km / ~1小時15分鐘)：續走 G30 連霍高速，途經亞洲最大「達坂城風力發電大風車群」。
12:15 - 13:45｜🔥【西遊神話】火焰山景區：打卡巨型金箍棒溫度計、寸草不生的赤紅雅丹山體，感受震撼的地貌景觀。
13:45 - 16:00｜🍇【葡萄採摘盛宴】葡萄溝：9 月正值葡萄盛產黃金季！漫步綠意盎然的葡萄長廊，在葡萄架下享用手抓飯與現摘甜葡萄（無核白、馬奶子），清涼消暑。
16:00 - 17:15｜💧【地下水利奇蹟】坎兒井民俗園：探索古代荒漠地下暗渠水利工程，了解清泉綠洲的生命之源。
17:15 - 18:30｜🕌【西域伊斯蘭古塔】蘇公塔 (額敏塔) 或 交河故城：參觀新疆最大伊斯蘭磚雕古塔或千年生土古城遺址。
18:30 - 21:00｜🚗 吐魯番 ➡️ 地窩堡機場 (180 km / ~2.5小時)：走 G30 連霍高速直達烏魯木齊機場，不進市區塞車。
21:00 - 22:30｜機場周邊晚餐 ＆ 22:30 還車：享用晚餐、打包行李，於 22:30 在機場租車中心完成還車。
23:00｜進入出境大廳：辦理返台登機手續與行李直掛（等待 9/13 02:05 起飛）。
💡 吐魯番自駕提示：
吐魯番氣溫約 22°C ~ 32°C，紫外線強且乾燥，請備妥防曬乳、遮陽帽、墨鏡與充足飲水。

🪪 換臨時駕照：飯店開立蓋章之「臨時住宿登記表」+ 台灣駕照 + 台胞證 + 2張一吋照片。
